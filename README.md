# 🌿 GreenNest Platform

A premium foliage e-commerce platform built with modern web technologies.

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion

### Backend
- Laravel
- MySQL
- Redis

- 🌿 Premium plant catalog
- 🛒 Shopping cart

- ❤️ Wishlist
- ⭐ Reviews & Ratings
- 📦 Order tracking
- 👤 User accounts
- ⚙️ Admin dashboard
- 📱 Fully responsive
- 🔒 Enterprise-grade security
